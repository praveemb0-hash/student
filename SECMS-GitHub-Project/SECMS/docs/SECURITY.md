# Security

## Admin
Full access to SECMS objects.

## Enrollment Officer
Create/edit Enrollment and read relevant Student/Course information.

## Instructor
Read enrollment information relevant to assigned work.

## Important org setup
The specification calls for private Enrollment sharing and instructor-specific visibility. Salesforce user/role/owner configuration is org dependent; verify Organization-Wide Defaults, sharing rules, field-level security and user assignments in the target org rather than assuming deployment alone completes them.
